# 正文与强调

<Subtitle>段落、软换行、中英混排，以及几种强调</Subtitle>

雨停的时候，书店门口的灯刚刚亮起来。有人把湿伞收好，靠在门边，翻开一本还没读完的书。街上的车声隔着玻璃变得很轻，纸页却很清楚：上一页留下的折角，一行读到一半的话，还有那些当时觉得平常、后来才慢慢想明白的句子。长段落适合看行长，也适合看视线从行末回到下一行时，是否还找得到自己的位置。

短句也要站得住。

这一行与下一行在源码里只隔一个换行。
它们仍属于同一段，第二行沿用正文的软换行与缩进。

写到“边界”时，可以用*普通强调*；真正需要留意的是**加粗文字**；需要更明确的标记时，则是***三重强调***。删去的想法也能留下痕迹：~~当时以为这就是全部~~。强调接着中文标点，像*这样*，以及（**括号里的补充**），都应该自然地融在句子里。

中英混排会遇到 TypeScript、React 和 MDX，也会遇到 `font-size: 16px` 这样的行内代码。_中文不倾斜，English in italics_。数字也有自己的节奏：2026 年 9 月 27 日，08:30，1,024 次，99.9%。标点则包括「引号」、『书名中的引文』、《作品名称》、省略号……以及一句话里的——停顿。

行内代码连续出现时，可以比较 `pathname`、`description` 和 `create` 的间距；链接可以接在[博客首页](/)之后。<small>这一句是小字号补充。</small>下标如 H<sub>2</sub>O，上标如 x<sup>2</sup>，也放在同一行观察。

# 引用与旁注

短引用之后接回正文。下一段长引用使用为样张写的文字，看看连续阅读时，字号、底色和缩进是否协调。

> 旧书店每天六点关门。到了五点五十分，店主就把门口的木牌翻过来，却从不催坐在窗边的人。
>
> “这本可以带回去。”他指了指桌上的书。
> “我还没决定要不要买。”
> “那就等读完再决定。”
>
> 年轻人抬头看了一眼。玻璃上映着一排刚亮起来的路灯，水沿着窗框慢慢往下走。他忽然觉得，今天没有赶上那班车，也不是什么坏事。
>
> 书里夹着一张旧车票。他把它挪到下一页，像替很久以前的某个人，把这本书又读下去了一点。

<AuthorNote>
  这里是作者暂时离开正文的一小段补充。文字变轻，边界稍稍收拢，让读者知道这是另一条思路。

  旁注也可以有第二段，包含*强调*、**重点**和 `inline code`。观察多段之间的距离，以及最后一段和角线之间的留白。
</AuthorNote>

> 外层引用先交代语境。
>
> > 内层再引用另一句话：“不要急，慢慢读。”
>
> 回到外层后，左侧边界与段落缩进应当仍然清楚。

<Subtitle>语法高亮、重点行、类型提示，以及公式的基线</Subtitle>

## 代码块

普通代码块包含缩进、空行和一行重点标记。

```js?lsp=false
function openBook(title) {
  const bookmark = { page: 24, title };

  /*** hl ***/return bookmark;
}

openBook('字里行间');
```

下面使用 TypeScript 类型提示。可以把鼠标移到 `bookmark` 或 `page` 上，查看推断结果。

```ts
interface Bookmark {
  title: string;
  page: number;
}

const bookmark: Bookmark = {
  title: '字里行间',
  page: 24,
};

function nextPage(current: Bookmark): Bookmark {
  return { ...current, page: current.page + 1 };
}

const next = nextPage(bookmark);
```

这一行配置故意不换行，用来观察代码块的横向滚动。

## 数学公式

行内公式 $a^2 + b^2 = c^2$ 夹在文字中间，后面再接一个分式 $\frac{1}{2}$，观察公式与汉字的基线，以及这一行的高度。

$$
\sum_{k=1}^{n} k = \frac{n(n+1)}{2}
$$

稍复杂一些的块级公式：

$$
\begin{aligned}
f(x) &= \int_0^x t^2\,\mathrm{d}t \\
     &= \left.\frac{t^3}{3}\right|_0^x \\
     &= \frac{x^3}{3}
\end{aligned}
$$
