## 内部排版样张

在仓库根目录运行 `pnpm run watch`，打开 <http://localhost:5678/__dev/typography/>。
首次运行前先执行 `pnpm run build:prepare`。

样张源码在 `dev/typography/index.mdx`，直接使用正式文章的模板、主题与 MDX 组件。
包含正文与强调、标题层级、引用与旁注、术语与夹注、列表与表格、代码与公式、图片与字体，以及嵌套组合。
可通过页首索引定位示例，用网站右上角的主题按钮检查深浅色，缩窄窗口检查移动端布局。

`package.json` 的 `devMain` 指定开发样张的文件范围；生产模式不会加载这些文件。
样张设为 `public: false`，不会出现在首页、标签或归档中。

## 出处注与参考资料

在正文需要引用的地方写一次 `<Ref />`，构建时自动按首次出现顺序编号，并在文章末尾生成「引用与参考资料」。不需要 import，也不需要另写列表或手动编号。

```mdx
这段描写像一个长镜头。<Ref id="debt" title="《无尽债务》" note="Andlao，第 4 章" />

在线资料。<Ref title="资料名称" href="https://example.com/source" />

再次引用同一资料。<Ref id="debt" />
```

- `title`：资料名称，首次声明必填。
- `href`：可选的原文地址；不填也可以引用书籍。
- `note`：可选的作者、章节、页码、补充说明。
- `id`：可选的文章内标记。复用时只写 `id`，沿用同一编号；完整资料仍只声明一次。

属性使用普通字符串。相同完整声明会合并；给出相同 `id` 却填写不同资料会报错。编号可跳到文末，返回链接可回到各次引用位置。原生 Markdown 脚注也可以继续使用，与 `<Ref />` 共用文末列表。
